INVENTARIO MUNICIPAL - SISTEMA DE GESTIÓN DE INVENTARIO

Este software ha sido desarrollado para facilitar la gestión de inventarios
en instituciones municipales. Incluye funcionalidades para:

- Gestión de usuarios y permisos
- Control de inventario de productos
- Registro de entradas y salidas
- Gestión de préstamos
- Auditoría de transacciones
- Generación de reportes

REQUISITOS DEL SISTEMA:
- Windows 10 versión 1809 o superior (x64)
- Java 25 (incluido en la instalación)
- JavaFX 25 (incluido en la instalación)
- MySQL 8.0 o superior (opcional, para base de datos remota)
