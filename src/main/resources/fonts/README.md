Fuentes DejaVu Sans para los reportes PDF (regular y negrita).
Se incluyen como recursos para que el exportador no dependa de las fuentes instaladas en Windows.

Procedencia: archivos DejaVu incluidos en la distribución local de TCPDF/phpMyAdmin.
Los TTF se recuperaron por descompresión zlib, sin modificar las fuentes.
La licencia se conserva en LICENSE-DejaVu.txt, extraída del campo de licencia del propio TTF.
Proyecto: https://dejavu-fonts.github.io/
